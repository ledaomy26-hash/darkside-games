# Настольные игры Dark Side

Шахматы и шашки против компьютера или живого соперника. Играются в браузере,
работают без интернета, ставятся на телефон как обычное приложение.

- Шахматы: `chess/`
- Шашки: `checkers/`

Собственные движки: генерация ходов, перебор с alpha-beta, уровни сложности.
Исходники игр — в отдельных репозиториях, здесь опубликована готовая веб-версия.
